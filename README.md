# Reindeer Ledger

**Reindeer Ledger** — настольное приложение для автоматизации обработки ведомостей учёта оленей, проверки данных и формирования бухгалтерской отчётности.

Разработчик: **KV/RaMIS Project Group**  
Версия: **0.6.0 Release Candidate**  
Лицензия: **MIT**

## Возможности

- Импорт исходных ведомостей XLSX.
- Просмотр и проверка записей.
- Ручная классификация закупных животных.
- Автоматическое сохранение и восстановление разметки.
- Расчёт количества голов и убойного веса.
- Формирование бухгалтерских таблиц XLSX.
- Экспорт отчётов в PDF и JSONL.
- Светлая и тёмная темы интерфейса.
- Встроенное руководство пользователя.
- Автономная работа без подключения к интернету.

## Поддерживаемые платформы

- **Linux:** запуск из исходного кода с Python и PySide6.
- **Windows 10/11:** подготовлена конфигурация сборки установщика с PyInstaller и Inno Setup. Windows-сборка находится на этапе тестирования.

## Запуск из исходного кода

Требуется Python и зависимости из `requirements.txt`.

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

В Windows используйте соответствующие команды активации виртуального окружения.

## Windows Installer

Проект включает сценарии автоматической сборки Windows-приложения с помощью GitHub Actions.

Установщик предусматривает:

- установку без необходимости отдельно устанавливать Python;
- ярлык на рабочем столе;
- запуск приложения после завершения установки;
- фирменную иконку;
- удаление приложения стандартными средствами Windows.

Подробности — в [BUILD_WINDOWS.md](BUILD_WINDOWS.md).

## Конфиденциальность

Приложение обрабатывает ведомости локально. Для основных функций не требуется подключение к интернету.

Перед публикацией репозитория убедитесь, что в него не включены реальные бухгалтерские документы и персональные данные.
